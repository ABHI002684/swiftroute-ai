# SwiftRoute AI

An intelligent logistics operations and decision support platform for monitoring deliveries, identifying delivery risks, prioritizing exceptions, and assisting logistics teams.

## Project Structure

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **AI:** Logistics intelligence and AI-powered assistance
- **Offline Support:** Local data access and queued synchronization

## Main Modules

- Operations Dashboard
- Delivery Management
- Delivery Risk Detection
- Logistics AI Assistant
- Analytics and Reporting
- Offline Synchronization

## Development

The project is organized into separate frontend and backend applications to support modular development and independent deployment.

## Data

The application will use synthetic logistics data for demonstration purposes.
